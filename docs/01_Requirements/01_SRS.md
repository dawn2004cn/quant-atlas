项目需求规格说明书 (SRS)

1. 引言与系统目标
本系统旨在打造一个本地优先（Local-First）、隐私安全、AI 深度赋能的跨市场通用量化交易操作系统 (Trading OS)。系统融合了 Agent 对话控制台、MCP 动态扩展、自动化策略进化实验室以及高可用多资产路由执行引擎。

> **产品决策（已确认 2026-08-06）：**
> - **D1** 前端主轨为 React 19 + Vite + Tailwind（`frontend/`），经典 Jinja 渐进日落；**不迁 Vue**。
> - **D2** A 股/国内执行近中期以 **QMT** 为准；CTP 与 IBKR 列入路线图 **P2**。
> - **D3** 历史 K 线权威写入为 **TimescaleDB + qlib_export CSV + qlib_bin**；ClickHouse / QuestDB / MySQL 历史分表不再作为入库主路径。
> - **D4** 新建 `quant-atlas-mcp` 暴露本地量化工具；与 wind/ifind/akshare 等数据 MCP 并存。
> - **D5** IBKR 为 P2 独立里程碑。
> - **D6** 「10 年分钟级回测 ≤10s」先建基准再优化，不以未验证数字宣称达标。
>

3. 功能需求规格 (Functional Requirements)
3.1 AI Agent 智能决策与 MCP 协议扩展
自然语言生成与审查：系统支持通过自然语言输入（如“编写一个基于 ETH 15分钟 RSI 底背离+成交量放大的突破策略”）生成 Python 代码。

MCP (Model Context Protocol) 服务端：暴露本地量化 API 给 LLM（如 Claude 3.5 Sonnet / DeepSeek-R1），包含：

get_historical_kline(symbol, timeframe, limit)：获取 K 线。

execute_backtest(strategy_code, params)：无缝调用回测引擎。

get_portfolio_status()：读取实盘/模拟持仓及 PnL。

多 Agent 辩论机制：

Research Agent 负责提出信号假设；

Risk Controller Agent 检查是否存在前瞻偏差（Look-ahead Bias）、硬编码止损缺失及过度拟合风险，合规后方可上线。

3.2 离线策略锦标赛 (Tournament Engine)
无监视进化：系统在非交易时段自动对策略池进行超参网格搜索或遗传算法迭代（借鉴 TradeSight 与 FreqAI 理念）。

自动化淘汰制：根据夏普比率（Sharpe > 1.8）、最大回撤（MDD < 12%）、胜率等指标自动筛选更新实盘/纸面交易（Paper Trading）策略池。

3.3 统一多资产路由层 (Unified Multi-Asset Gateway)
数据模型标准化：抽象抹平不同市场字段（Crypto, US Stocks, Futures），统一使用 OrderRequest、Position、Tick。

驱动解耦：底层支持动态加载不同 Adapter：

CryptoCCXTAdapter：对接 Binance, OKX 现货与永续合约。

QMTAdapter（近中期）：对接国内 A 股等 QMT 执行通道。

IBKRAdapter（P2）：对接 Interactive Brokers API，处理美股与外汇。

CTPAdapter（P2）：对接国内商品期货 CTP 接口（或与 QMT 能力重叠时以文档为准二选一）。

3.4 极速回测与风险熔断引擎
事件驱动与向量化混合回测：支持精准滑点模拟、不同交易所阶梯手续费计算。

硬编码风控守卫 (Risk Guard)：独立于 AI 之外运行的底线代码。

单日账户最大回撤超过 5% 强制紧急平仓（Flatten All）。

策略连续止损 3 次自动暂停 API 执行权限并触发 Telegram 报警。

4. 非功能需求规格 (Non-Functional Requirements)
安全性 (Security)：API Key 仅授权交易与查询，严禁开启提现权限；LLM 策略代码必须在 restricted 环境（Docker/沙箱）中运行，避免任意代码执行漏洞。

性能 (Performance)：Redis 实时行情推送延迟控制在 50ms 内（SLO，需可观测）；回测引擎支持单机多核并行化，10 年分钟级数据回测目标 10 秒内完成（先基准后优化）。

可用性 (Usability)：提供现代化响应式 Dashboard（React SPA），支持 TradingView Lightweight Charts 画线与指标叠加。
