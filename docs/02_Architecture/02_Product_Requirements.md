# 02 产品需求规格书 (Product Requirements Document)

**文档版本：** v1.0 | **定位：** 用户频谱需求矩阵

## 1. 概述
本规格书定义了 Quant-Atlas 为满足不同资金规模、专业程度和合规要求的用户群体而需构建的功能集合。

## 2. 用户需求矩阵

### 2.1 散户 (Retail Traders)
**核心痛点：** 缺乏编程能力、缺乏系统化交易知识、情绪化交易。

| 功能模块 | 需求描述 | 预期目标 |
| :--- | :--- | :--- |
| **NL $\rightarrow$ Strategy** | 自然语言直接生成策略逻辑，无需接触代码。 | 实现“所说即所得”的策略构建。 |
| **AI 投资教练** | 基于 `Evidence Graph` 的决策解释。 | 提高用户信任度，降低盲目跟风。 |
| **镜像交易** | 一键订阅 `Alpha Marketplace` 顶尖策略。 | 构建“量化社交”生态。 |
| **心理状态追踪** | 分析手动干预与策略执行的偏差。 | 辅助用户建立纪律性交易习惯。 |

### 2.2 量化小团队/精品店 (Quant Boutiques)
**核心痛点：** 研发周期长、因子挖掘重复率高、回测速度慢。

| 功能模块 | 需求描述 | 预期目标 |
| :--- | :--- | :--- |
| **自动因子挖掘机** | 引入遗传编程/符号回归自动化组合算子。 | 将因子发现周期缩短至小时级。 |
| **向量化回测引擎** | 毫秒级参数扫描（Grid Search）。 | 极速验证因子有效性。 |
| **另类数据连接器** | 预置情感分析、产业链数据等接口。 | 提供非共识数据的获取能力。 |
| **协作研究空间** | 云端共享因子库、研究笔记和报告。 | 提升团队内部的研发协同效率。 |

### 2.3 投资公司/家族办公室 (Investment Companies)
**核心痛点：** 策略单一、缺乏宏观视角、波动率控制不足。

| 功能模块 | 需求描述 | 预期目标 |
| :--- | :--- | :--- |
| **多策略组合优化器** | $\text{Risk Parity}$ 或 $\text{Black-Litterman}$ 动态权重分配。 | 优化组合 $\text{Sharpe Ratio}$。 |
| **宏观政体感知引擎** | 将 `MarketRegime` 升级为宏观周期识别。 | 实现策略随环境自动切换。 |
| **多资产类兼容** | 股票、期货、期权、外汇、加密货币全覆盖。 | 实现跨品种对冲。 |
| **税后收益优化器** | 计算交易税费与滑点，优化税务结转。 | 提升实际到手收益率。 |

### 2.4 基金公司 (Fund Managers)
**核心痛点：** 收益来源不透明、合规风险高、规模回撤管理。

| 功能模块 | 需求描述 | 预期目标 |
| :--- | :--- | :--- |
| **工业级归因分析** | $\text{Brinson}$ 模型拆解配置/选股/风格贡献。 | 提供透明、专业的收益报告。 |
| **合规预检系统** | 强制执行持仓上限、行业集中度等阈值。 | 确保交易 100% 合规。 |
| **决策审计追踪链** | 每笔交易关联不可篡改的 AI 证据快照。 | 通过监管审计，责任可溯源。 |
| **主从账户管理** | 支持主策略账户同步至数千个子账户。 | 实现资产规模快速扩张。 |

### 2.5 大型机构 (Large Institutions / Whales)
**核心痛点：** 交易冲击成本极高、延迟竞争激烈、数据泄露风险。

| 功能模块 | 需求描述 | 预期目标 |
| :--- | :--- | :--- |
| **冲击成本预测模型** | 基于 LOB 深度预测大单对价格的实时影响。 | 最小化交易损耗 (Slippage)。 |
| **高级执行算法 (Algo)** | 内置 $\text{VWAP}$、$\text{TWAP}$、$\text{Iceberg}$ 等。 | 在不惊动市场的情况下完成建仓。 |
| **私有化/联邦部署** | 支持离线部署或通过联邦学习更新模型。 | 满足最高级别金融隐私安全需求。 |
| **极细粒度 RBAC** | 实现研究员、交易员、风控员严格隔离。 | 消除内部道德风险。 |
