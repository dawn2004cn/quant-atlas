# 变更记录

## [2.0.0] - 2026-03-31

### 主要功能更新

- **多数据源支持**：集成akshare、腾讯财经、搜狐财经、Yahoo Finance等多个数据源
- **智能缓存系统**：实现Redis和SQLite双缓存机制，根据数据类型和大小智能选择缓存系统
- **增强型数据获取器**：创建`enhanced_data_fetcher.py`，支持多数据源备选和并发获取
- **市场情绪分析**：基于全市场股票数据的综合情绪评分系统
- **选股策略**：实现中长线选股策略和技术指标选股
- **Web界面优化**：改进用户界面，支持实时市场监控

### 代码重构

- **服务容器**：实现Service Container模式，统一管理服务实例
- **依赖注入**：实现依赖注入，提高代码可测试性和可维护性
- **接口隔离**：拆分过大的接口，确保接口功能单一
- **缓存接口统一**：确保Redis和SQLite缓存的方法一致性
- **错误处理**：完善的错误处理和日志记录

### 性能优化

- **并发数据获取**：使用多线程并发获取股票数据
- **缓存策略**：针对不同类型数据使用不同的缓存策略
- **数据压缩**：优化缓存数据存储，减少存储空间
- **网络请求优化**：添加重试机制和超时处理

### 修复的问题

- **akshare不稳定**：添加多数据源备选，提高数据获取稳定性
- **缓存不一致**：统一Redis和SQLite缓存的方法接口
- **市场数据获取失败**：添加多重数据源备选和错误处理
- **前端显示问题**：修复市场异动和排行榜数据显示
- **路由端点错误**：修复Flask路由端点引用问题
