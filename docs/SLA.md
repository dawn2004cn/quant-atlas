# Quant Atlas Beta SLA（2026-06）

> 面向零售内测/研究辅助场景的服务目标，**不构成对投资收益的承诺**。

## 服务定位

- **产品**：A 股零售量化研究与信号辅助平台
- **非目标**：证券投资顾问、代客理财、实盘下单通道

## 可用性（Beta）

| 指标 | 目标 | 说明 |
|------|------|------|
| 核心 API 可用性 | 99.0% / 月 | `/api/v1/daily-workbench`、`/health`、自选与行情主路径 |
| API P95 延迟 | < 2s | 非全市场扫描类读接口 |
| 计划内维护 | 提前 24h 公告 | 站内横幅或任务消息 |

**不计入 SLA 的情况**：第三方行情源中断、用户网络故障、全市场 AkShare 限流、LLM 供应商故障。

## 数据新鲜度（尽力而为）

| 数据类型 | 目标延迟 |
|----------|----------|
| A 股现货行情 | ≤ 15 分钟（依赖外部源） |
| 基本面/财报 | ≤ 1 个交易日 |
| AI 研报缓存 | 按任务完成时间戳展示 |

## 人工决策复核（Human-in-the-loop）

| 项 | 标准 |
|----|------|
| 入队条件 | 预交易风控未通过、风险分 < 45、AI 置信度偏低 |
| 复核 SLA | **24 小时**内用户确认/驳回/修正（产品提示，非法律义务） |
| 队列容量 | 免费版 20 条 / 专业版 200 条（滚动淘汰最旧 pending） |

- GitHub Issues（技术问题）
