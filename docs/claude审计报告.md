[CRITICAL] 密码哈希使用无盐 SHA-256

位置: modules/user/services/user/auth_service.py:20-21

hashlib.sha256(password.encode("utf-8")).hexdigest()  # 无盐！

同时支持遗留的 SHA-1 哈希。等同于明文存储密码。

Fix: 迁移到 bcrypt 或 argon2-cffi，实现 login-time re-hash：

from passlib.hash import bcrypt_sha256

# 登录时: if bcrypt_sha256.verify(password, stored_hash): rehash

最真实的建议

这个项目的核心问题是：功能增长速度远超架构治理能力。446 个 modules/ 文件  具文件，都是feature-driven堆积的结果。

不要试图一次性重构回四层架构 — 446 个模块的迁移风险极大。建议：

1. 先止血（Phase 1）：解决所有安全问题
2. 再止血+止血（Phase 2）：拆分最大的 God 文件
3. 然后立规矩（Phase 3）：引入 lint 规则、测试覆盖率门槛、代码审查清单
4. 最后优化（Phase 4）：性能、可访问性、用户体验

每一阶段做完都要有测试证明没有破坏现有功能。
