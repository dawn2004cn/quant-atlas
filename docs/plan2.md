散户急需的 5 大新功能设计（优先级排序）
1. 每日 AI 智能选股（每日三支票 / Top 5 推荐）
功能名称：AI 早盘推荐（Daily AI Picks）
散户核心需求：每天早上最想知道“今天该看哪几只票？”
功能描述：

每天早盘前（9:00 前）自动生成 3-5 只 AI 推荐股票。
每只票必须包含：
一句话核心逻辑（白话版）
产业链位置与机会点
建议买入区间 / 止盈价 / 止损价
预期盈亏比 + 历史类似信号胜率（基于回测）
风险等级（低/中/高）
“一键加入自选股”按钮


技术实现：

使用现有 LangGraph 多智能体（Macro + Fundamental + Technical + Risk + Investment Manager）
结合 Qlib / 回测引擎给出胜率背书
Celery 定时任务每天早 7:30-8:30 运行

用户价值：把“每天选股”从痛苦变成爽快的一键操作，是提升日活最强的功能。

2. 一键 AI 诊股报告（个股深度诊断）
功能名称：AI 诊股（AI Stock Diagnosis）
散户核心需求：看上一只票后，想快速知道“这票到底行不行？该不该买？”
功能描述：

用户输入任意股票代码或名称 → 一键生成结构化 AI 诊股报告
报告包含以下模块（散户友好版）：
一句话诊断：如“当前处于中线反弹阶段，短期有资金关注，但估值偏高”
产业链梳理图（简易流程图）
多维度分析：基本面、技术面、资金面、情绪面（用你的多智能体生成）
操作建议：建议持仓比例、买卖参考区间、止盈止损价
风险提示：主要风险点 + 黑天鹅预警
历史回测参考：类似形态/信号的历史胜率


技术实现：

调用现有 LangGraph 多智能体工作流 + FinGPT + 基本面数据中心
输出结构化 JSON + Markdown 双格式，便于前端展示

差异化：不是简单 LLM 总结，而是“多智能体共识 + 真实回测数据支撑”。

3. 智能持仓管家 + 动态止盈止损追踪
功能名称：持仓守护者（Position Guardian）
散户核心需求：买了票之后，最怕“拿不住”或“卖早了”
功能描述：

用户把股票加入“持仓分组”后，系统自动进入追踪模式
提供以下能力：
实时动态止盈 / 止损建议（结合 ATR、技术形态、风险 Agent）
持仓盈亏比与贡献度分析
信号旗触发提醒（突破、背离等）
每周/每月持仓复盘报告（胜率、平均盈亏比、最大回撤）
“是否该减仓/止盈/加仓”智能建议


技术实现：

扩展现有自选股系统，增加 is_holding 字段和持仓成本、持仓数量
与 Risk Manager Agent + 信号旗模块深度集成
使用 Celery + WebSocket 实现实时预警


4. 个性化 AI 投资经理（专属对话助手）
功能名称：我的 AI 投顾（Personal Investment Manager）
散户核心需求：想有一个“懂我”的助手，可以随时聊天、复盘、问策略
功能描述：

一个长期记忆的 AI 投资经理 Agent
支持自然语言对话，例如：
“我重仓了贵州茅台，现在该怎么办？”
“帮我分析一下我的自选股组合风险”
“我适合做短线还是波段？根据我的风格推荐”

记住用户风险偏好、投资风格、历史操作习惯
每周自动给用户发送“本周复盘 + 下周建议”

技术实现：

在现有 LangGraph 多智能体基础上增加 Long-term Memory（使用 pgvector 或 Redis）
升级 “投资经理” Agent 为支持多轮对话 + 用户画像绑定


5. 我的交易复盘与胜率实验室
功能名称：交易复盘室（Trade Review Lab）
散户核心需求：想知道自己“到底哪里做得好、哪里总是亏钱”
功能描述：

自动记录用户所有操作（加入自选、买入信号点击、AI 推荐采纳等）
提供以下复盘功能：
历史交易/信号胜率统计
按策略、按行业、按持仓周期的盈亏分析
“我的常见错误”总结（如经常过早止盈、追高被套等）
与 AI 推荐的对比分析（“AI 推荐后我实际操作胜率”）
一键生成月度/季度复盘报告（图文并茂）


技术实现：

新增操作审计日志表（AuditLog）
与现有回测引擎、Qlib 结合进行统计分析
使用 LangGraph 生成自然语言复盘总结
