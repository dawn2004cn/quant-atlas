上线方案：用户权限系统、页面管理与自选股深度设计（让用户“离不开”你的平台）
你现在的平台已经非常强悍（多源行情 + TDX + Qlib + FinGPT + LangGraph 多智能体 + 信号旗 + 投资经理等）。上线后，要让炒股一族每天主动打开，核心在于“与用户密不可分”：通过精准权限控制 + 个性化页面管理 + 智能自选股系统，把平台变成用户的“个人投资大脑 + 持仓管家 + 决策助手”。
以下是完整、可落地的上线方案，分为三大部分：用户权限系统、页面管理、自选股系统，并给出 Cursor 开发计划。
1. 用户权限系统（安全 + 个性化 + 合规）
设计原则：最小权限 + 渐进式解锁 + 数据隔离 + 操作审计。避免“一刀切”，让不同用户感受到“专属感”。
推荐角色体系（RBAC + Attribute-Based）：

Guest（访客）：浏览行情、AI 诊股演示、有限选股。不能保存自选股、不能用回测、不能保存报告。
Free 用户：注册后 → 可创建 3-5 个自选股分组、每日 3 次 AI 诊股、基本每日推荐、朋友圈查看。限制高级多智能体深度报告和 Qlib 复杂回测。
Pro 用户（付费）：无限自选股 + 分组 + 预警、完整多智能体报告（产业链梳理 + 胜率追踪）、个性化投资经理记忆、导出策略代码、组合风险压力测试、无限每日推荐。
VIP / 机构（可选后期）：多账户管理、团队协作、API 访问、白名单数据源、专属 Agent 训练。

关键权限点（与用户“密不可分”的设计）：

数据权限：自选股、持仓记录、历史回测报告、AI 对话历史 → 完全用户私有（数据库行级权限或 tenant_id）。
功能权限：AI 深度报告、实盘信号、Qlib 高级回测、高频预警 → Pro 解锁。
市场权限：A股免费，港股/美股/Crypto 根据用户风险评测或付费解锁。
操作审计：记录所有 AI 推荐点击、加入自选、回测执行等，用于“我的足迹”和复盘。
隐私与合规：支持数据导出、删除账号（带自选股/报告备份）、GDPR-like 同意机制。重要操作（如删除自选组）二次确认。

实现建议：

使用 FastAPI + JWT/OAuth2 + RBAC 中间件。
结合用户画像（风险偏好、投资风格、活跃度）动态调整权限。
登录方式：手机号/微信/QQ 一键登录（提升转化）。

2. 页面管理（让用户感觉“这是我的平台”）
核心目标：首页高度个性化、核心功能一键直达、跨设备无缝同步。
推荐页面结构（移动端优先，Web 同步）：

首页（Dashboard）：卡片式布局
顶部：个性化早报/晚报（AI 生成）
“今日 AI 推荐 Top 3” 卡片（带买卖点、止盈止损、胜率）
“我的持仓风险仪表盘”（整体风险评分 + 预警）
“投资经理问候 + 快捷对话”入口
“朋友圈/消息”最新动态

自选股页（核心高频页）：Tab + 分组管理（短线、价值、观察、行业等）
支持拖拽排序、批量操作、实时预警
每只股票显示：最新价 + AI 诊股快捷按钮 + 信号旗 + 止盈止损线

AI 研究中心：AI 诊股、产业链梳理、每日推荐历史、多智能体报告查看
我的组合：持仓管理 + 模拟 vs 实盘对比 + 胜率/盈亏比追踪
个人中心：权限管理、订阅升级、数据导出、复盘总结、设置（风险偏好、推送偏好）

高级页面管理功能：

自定义首页：用户可拖拽卡片顺序、隐藏/显示模块。
多设备同步：自选股、报告、偏好实时云同步。
暗黑/亮色 + 字体大小适配（散户很多中老年用户）。
快捷入口：底部导航栏（首页 / 自选 / AI / 消息 / 我的）。

3. 自选股系统（让用户每天回来查看的核心黏性功能）
这是最密不可分的部分，必须做强、做深、做智能。
核心功能设计：

分组管理：默认 + 自定义分组（短线机会、核心持仓、观察列表、行业跟踪等），支持无限分组（Pro）。
智能排序与筛选：按 AI 推荐强度、涨幅、风险评分、胜率潜力排序。
实时/批量预警：价格突破、信号旗触发、产业链异动、风险变化 → 推送（站内 + 微信/短信可选）。
AI 增强：
一键 “AI 批量诊股” 整个自选组。
自动建议 “调仓建议”（哪只该止盈、哪只该加仓）。
每周/每月自选股表现复盘报告（胜率、盈亏比贡献）。

可视化：自选股列表嵌入 mini K 线 + 信号旗 + 止盈止损价位标注。
社交轻互动：自选股可生成分享卡片（朋友圈），但加平台水印 + 免责声明。
导入/导出：支持从通达信/其他 App 导入自选股，导出 Excel。

技术实现要点：
数据库表。
使用 Redis 缓存高频读写的自选股列表 + 实时行情推送。
与 LangGraph 多智能体深度集成：自选股变化 → 触发 Risk Manager 或 Investment Manager Agent 分析。
