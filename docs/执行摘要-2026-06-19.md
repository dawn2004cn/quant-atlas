## 逐轮详解

### 第 1 轮 — 存量 Bug 清理
- **`??` 编码损坏**：`trade_plan_service.py` 18 处 GBK→UTF-8 转换丢失的中文字符全部修复
- **`except:pass`**：AST 扫描确认 8 处，均为设计意图清晰的静默失败（skip）
- **`.env` 凭据**：`git rm --cached` 从 git 索引中移除，确认从未被提交到历史
- **CSRF/安全**：`csrf_protection.py` 收紧为 GET-only OAuth callbacks、session cookie Secure+SameSite=Lax

### 第 2 轮 — RD-Agent Windows 适配
- **`_patch_data_folder_intro()`**：`QTDockerEnv.prepare()` 硬编码 Docker Desktop → 创建空文件夹 + no-op patch
- **`_patch_qlibfb_workspace_execute()`**：`QlibFBWorkspace.execute()` 的 Docker/Conda 分支 → `subprocess.run(["qrun", ...])` 本地子进程
- **`qrun.exe`** 已验证在 Windows PATH 中可用
- 覆盖全部 4 个 Docker/Conda 依赖入口

### 第 3 轮 — 测试门禁
- **`.pre-commit-config.yaml`**：6 个钩子（trailing-whitespace, end-of-file, check-yaml, check-added-large-files, detect-private-key, ruff + py-compile + contract-audit）
- **`tests/smoke/test_app_boot.py`**：10 个测试覆盖核心路由注册、模块导入、`??` 残留检测
- **`.github/workflows/ci.yml`**：新增独立 `smoke` job（无需 MySQL/Redis），拆分 `lint/test/smoke` 三个并行 job
- **`pyproject.toml`**：ruff 新增 S（安全）、BLE（异常处理）、RUF100 规则
- **`Makefile`**：`make dev/lint/test/smoke/compile/precommit`

### 第 4 轮 — WebSocket Gateway
- **`bootstrap.py:140`**：`init_realtime()` 首次接入 `create_app()` 调用链（此前为死代码）
- **`ws_gateway/__init__.py`**：独立 SocketIO 进程，`WS_GATEWAY_MODE=1` 时启动在端口 5001
- **`websocket_adapter.py`**：Redis Pub/Sub 桥接 + session 认证
- **`run.py`**：三模式入口（HTTP only / SocketIO / Gateway）
- **`market_stream.py`**：`_is_real_data_source()` 硬返回 False → 读环境变量

### 第 5 轮 — SPA StockDetail
- **`TradePlanPanel.tsx`**：React 版买卖计划完整组件（价格卡片/风控徽章/决策副驾驶/理由/失效条件/风险卡片/情景推演）
- **`types/stock.ts`**：新增 `TradePlan` 完整类型定义
- **`pages/StockDetail.tsx`**：集成 `TradePlanPanel` 在行情和 AI 面板之间

### 第 6 轮 — Data Gateway
- **`app/core/data_gateway.py`**：统一入口，15 个 repo 属性懒加载
- **`bootstrap.py`**：`app.data_gateway = DataGateway(settings)` 注入
- 不修改现有 `deps.py` 工厂函数——DataGateway 在其上包一层

### 第 7 轮 — 策略加密存储
- **`mysql_factor_vault.py`**：写入时 `_encrypt(formula)`，读取时 `_decrypt(formula)`，所有 4 条读写路径全覆盖
- **`artifact_registry.py`**：写入时 `encrypt()` 加密 factor_formulation/description/code_preview，读取时 `_decrypt_artifacts()`
- 密钥：`KEY_ENCRYPTION_KEY` / `FLASK_SECRET_KEY` → PBKDF2-SHA256(480K) → AES-256-GCM

### 第 8 轮 — 回测进度 SSE
- **`sse_progress.py`**：`publish_progress(run_id, pct, msg)` 发布到 Redis PubSub
- **`qlib_pipeline.py`**：`GET /api/v1/qlib/progress/<run_id>` SSE 端点（30 秒超时）
- **`rdagent_tasks.py`**：因子循环 `_progress()` 回调集成 `publish_progress()`

### 第 9 轮 — SPA Alpha Factory
- **`AlphaFactory.tsx`**：6 个 Tab（实验/知识库/验证/模型选择/周会/影子测试），5 个内联子组件
- **`types/alpha.ts`**：6 个类型定义
- **`App.tsx`** + `base.html`：路由和导航链接

### 第 10 轮 — 前端性能优化
- **`React.lazy`**：6 个重量级页面代码分割（AlphaFactory 12kB、SignalFlag 5kB 等，首屏 332kB）
- **分页**：Signal Flag 表格从全量 200 行渲染改为每页 100 行
- **Vite build**：9 个异步 chunk，构建 3.89s

### 第 11 轮 — 国际化 i18n
- **`i18n.ts`**：i18next 初始化（中/英双语言，fallback 为英文）
- **`LanguageSwitcher.tsx`**：导航栏切换按钮
- **`Layout.tsx`**：全部导航文字改为 `t()` 翻译函数

### 第 12 轮 — Repo 层瘦身
- 删除 25 个死 shim 文件（18 个 root shim + 6 个 facade 委托 + 1 个 `__init__.py`）
- 修复 2 处隐藏的 `Index` 未导入 bug（`trading.py`、`advanced.py`）
- 保留 2 个高频 shim（`deps.py` 15+ 引用、`factory.py` 3 引用）
