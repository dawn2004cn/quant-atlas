# Quant-Atlas 用户价值功能路线

## 当前判断

quant-atlas 已有很强的底座：多源行情、TDX 本地数据、选股、回测、Qlib、FinGPT、LangGraph 多智能体、组合与风险、信号旗、投资经理、朋友圈/消息等。现在最大问题不是“功能不够”，而是普通炒股用户面对大量能力时，缺少一个清晰的每日使用路径。

目标应从“展示很多工具”转为“每天回答四个问题”：

- 今天市场能不能做？
- 我该看哪些票？为什么？
- 买了以后怎么控风险？
- 结果对不对，哪里需要修正？

## 推荐优先级

### 第一优先级：每日决策工作台

新增一个“今日操盘台”页面，聚合市场状态、自选股异动、策略候选、风险提示、AI 摘要和待办动作。它应该成为登录后的默认入口，而不是让用户在多个页面之间跳转。

可复用现有能力：
- 市场全景与情绪：`app/presentation/web/pages.py`、市场类 API
- 选股：`app/application/services/selection_source_service.py`
- 策略/回测：`app/application/services/strategy_service.py`
- AI 分析：`app/application/services/ai_analysis_service.py`
- FinGPT 预测/情感：`app/application/services/fingpt_application_service.py`
- 风险与组合：`app/application/services/risk_service.py`、`app/application/services/portfolio_service.py`

用户价值：用户每天打开平台后，不需要知道 Qlib、FinGPT、信号旗分别在哪，只看到“今天该关注什么”和“为什么”。

### 第二优先级：自选股智能体

围绕自选股做“持仓/关注票管家”：自动识别突破、跌破、放量、财报更新、新闻风险、策略信号变化，并给出清晰解释。

建议功能：
- 自选股每日健康分：趋势、量能、资金、新闻、基本面、风险五个维度。
- 异动原因解释：不是只提示“上涨 5%”，而是说明“放量突破 20 日高点 + 同行业上涨 + 新闻情绪偏正”。
- 自选股分组雷达：短线、波段、中长线、观察池分别展示不同信号。
- 一键深度分析：从自选股卡片直接进入 AI 研究或投委会分析。

用户价值：大多数股民最关心自己的票，不是全市场所有票。把已有 AI/策略能力绑定到自选股，会显著提升留存。

### 第三优先级：买卖计划与风控卡片

目前很多平台强调“选出牛股”，但用户真正亏损常来自仓位、止损、追高和没有计划。quant-atlas 应该把风控做成用户可执行的计划。

建议功能：
- 买入前计划卡：买入理由、失效条件、止损位、目标位、仓位建议、最大亏损金额。
- 持仓风险提示：跌破关键位、回撤超阈值、新闻风险、波动率异常。
- 组合暴露检查：行业集中度、单票集中度、市场风格暴露。
- 情景推演：如果大盘跌 2%、个股跌 5%，组合大概损失多少。

用户价值：把“我看好”转成“我能承受多大损失、错了怎么办”，这是散户最缺也最愿意持续使用的能力。

### 第四优先级：信号到模拟交易闭环

已有信号旗、投资经理、组合和回测能力，下一步应把信号转成模拟交易闭环，而不是只停留在列表。

建议功能：
- 信号生成后可加入“模拟观察单”。
- 自动记录入场价、触发原因、策略来源、AI 解释。
- 后续跟踪最大收益、最大回撤、是否触发止损/止盈。
- 按策略、来源、市场环境统计胜率与盈亏比。

用户价值：用户会逐渐知道“哪些信号适合自己”，平台也从一次性选股工具变成长期陪伴型工具。

### 第五优先级：AI 可信度与证据链

FinGPT 和多智能体能力很强，但对普通用户来说，AI 结论必须可验证、可追溯、可比较。

建议功能：
- 每个 AI 结论必须展示证据：行情、新闻、财务、回测、策略信号。
- AI 预测增加历史命中率/校准：过去类似预测涨跌是否准确。
- Bull/Bear 双方观点简化展示：看多理由、看空理由、关键分歧。
- 用户反馈：这条分析是否有用，后续用于优化提示词和排序。

用户价值：降低“黑箱 AI 荐股”的不信任感，让 AI 更像研究助理而不是算命工具。
