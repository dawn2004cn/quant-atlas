### T-2 · 跨进程事件序列化协议未统一【P2 · ✅ 已完成 2026-06-15】

**现状证据**
- 本地 `EventBus`（`app/core/event_bus.py`）传递 **dict**，无 schema 约束。

- `event_bus.py` 两处宽泛捕获：L344、L416（`except Exception` 吞错）。
- 风险：跨进程事件可能因字段漂移而丢失/误读，宽泛捕获使故障沉默。

**目标**
- 为跨节点事件定义统一 schema（JSON Schema 或 pydantic 模型），序列化/反序列化集中在一处。

**执行结果**
- 新增 `EventEnvelope`、`EventSchemaError`、`event_to_envelope()`、`event_from_envelope()`、`event_to_json()`、`event_from_json()`、`event_schema()`。
- `EventBus._event_to_dict()` 现在返回统一 envelope。
- WebSocket broadcast 现在发送 envelope，并在失败时用 `logger.exception()`。
- 宽泛 `except Exception` 从 2 处降为 1 处：仅保留在 handler 执行边界，且已有 `logger.exception()` 与 `_handler_failures` 记录。
- 新增 `tests/core/test_event_serialization.py`，覆盖 MarketRegime/Trade 事件往返、schema、未知事件、缺失字段。
