# 变更记录

## 2024-12-01 - Redis缓存迁移

### 主要变更

1. **Redis缓存实现**
   - 创建了 `redis_cache.py` 文件，实现了Redis缓存后端
   - 设计了完整的Redis存储结构，包括股票基本信息、历史数据、技术指标等
   - 支持近三年历史数据的存储和管理

2. **数据导入工具**
   - 创建了 `import_history_to_redis.py` 脚本，用于将历史数据从CSV文件导入到Redis
   - 支持数据筛选，只保留近三年的历史记录
   - 实现了数据导出功能，方便数据备份和迁移

3. **配置管理**
   - 创建了 `config.py` 文件，统一管理缓存配置
   - 支持通过配置切换缓存类型（Redis/SQLite）

4. **缓存工厂**
   - 创建了 `cache_factory.py` 文件，实现了缓存实例的统一获取
   - 提供了无缝切换不同缓存后端的能力

5. **代码修改**
   - `web_app.py`: 修改为使用CacheFactory获取缓存实例
   - `tech_indicators.py`: 从Redis获取历史数据，提高数据获取速度
   - `long_term_selector.py`: 使用Redis作为缓存后端，优化选股速度
   - `update_history_data.py`: 支持将数据更新到Redis

6. **性能优化**
   - 历史数据查询速度显著提升
   - 选股过程更加高效
   - 系统响应速度加快

### 技术细节

- **Redis数据结构**:
  - `stock:{code}`: 股票基本信息（Hash）
  - `stock_history:{code}`: 股票历史数据（Sorted Set，按日期排序）
  - `stock_history_status:{code}`: 历史数据更新状态（Hash）
  - 其他相关数据结构

- **数据管理**:
  - 自动清理超过三年的历史数据
  - 支持增量更新
  - 提供数据导出功能

- **兼容性**:
  - 保持与原有SQLite缓存的接口兼容
  - 支持无缝切换

### 影响范围

- 所有涉及历史数据的功能都已迁移到Redis
- 选股、技术指标计算等功能的性能得到显著提升
- 系统整体响应速度加快

## 2024-11-15 - 历史数据管理

### 主要变更

1. **历史数据更新**
   - 创建了 `update_history_data.py` 脚本，用于更新历史数据
   - 支持增量更新，只更新新增的数据
   - 记录更新状态，避免重复更新

2. **定时任务**
   - 创建了 `schedule_history_update.py` 脚本，用于定时更新历史数据
   - 设置每天16:00自动执行更新

3. **Web接口**
   - 添加了历史数据更新的API接口
   - 支持异步更新和状态查询
