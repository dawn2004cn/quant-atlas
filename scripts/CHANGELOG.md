# 项目修改记录

## 2026-04-06

### 重大修改

1. **使用StockScreenerEngine选股引擎**
   - 修改了 `long_term_selector.py`，使用 `advanced_indicators.py` 中的 `StockScreenerEngine` 选股引擎
   - 注册了28种选股模型，提高了选股的多样性和准确性

2. **修改中长线选股逻辑**
   - 从缓存中读取历史数据进行选股，不在线上获取，提高了效率
   - 只要满足一个模型就推荐股票，增加了选股的覆盖面
   - 标记股票符合的模型名称，提高了选股的透明度

3. **修复编码错误**
   - 移除了 `advanced_indicators.py` 中的所有emoji字符，解决了gbk编码错误问题
   - 确保了所有输出都能正确显示

## 2026-04-05

### 重大修改

1. **修复回测引擎缓存回退功能**
   - 修改了 `backtest_engine.py` 中的 `DataFetcher` 类，使其优先从缓存获取历史数据
   - 优化了缓存数据的判断逻辑，确保只要有数据就使用缓存
   - 确保了缓存数据的日期范围正确过滤

2. **解决akshare接口不稳定问题**
   - 为 `hybrid_data_source.py` 中的 `_get_akshare_history` 和 `_get_akshare_realtime` 方法添加了重试机制
   - 增加了最大重试次数和重试延迟，提高了数据获取的稳定性

3. **修复交易记录盈亏计算错误**
   - 修改了 `utils.py` 中的 `execute_trading_strategy` 函数，使用买入价格而不是前一天的收盘价计算盈亏
   - 确保了交易记录的准确性

4. **优化TAU策略**
   - 修改了 `backtest_engine.py` 中的 `TAUStrategy` 类，调整了评分阈值
   - 将买入条件从70分降低到45分，卖出条件从40分降低到30分
   - 使策略能够产生交易信号和收益

5. **修复编码错误**
   - 移除了所有文件中的emoji字符，解决了gbk编码错误问题
   - 确保了所有输出都能正确显示

6. **提高数据获取稳定性**
   - 修改了 `_get_sina_history` 方法，使用 `data_fetchers.py` 中的搜狐接口
   - 修改了 `_get_eastmoney_history` 方法，使用 `data_fetchers.py` 中的腾讯接口
   - 增加了多数据源回退机制，确保即使一个数据源失败，也能尝试其他数据源

## 2026-04-01

### 重大修改

1. **修复SQLite线程安全问题**
   - 修改了 `stock_cache_db.py`，使用局部连接而不是共享连接
   - 解决了"SQLite objects created in a thread can only be used in that same thread"错误

2. **增加市场情绪和市场异动缓存**
   - 在 `redis_cache.py` 和 `stock_cache_db.py` 中添加了市场情绪和市场异动缓存方法
   - 提高了数据获取的速度和稳定性

3. **修复全市场股票列表加载失败问题**
   - 增强了 `services/market_service.py` 中的全市场股票列表缓存回退机制
   - 确保即使在今日未交易的情况下也能从缓存中显示最近的交易日的数据

4. **修复Excel文件读取错误**
   - 在 `update_stock_history_to_csv.py` 中修复了Excel文件读取错误
   - 支持从Astock20260331.xls读取股票代码和上市日期

5. **修复北交所股票无法获取问题**
   - 在 `data_fetchers.py` 中为北交所股票添加了特殊处理
   - 确保所有数据源都能正确处理北交所股票
