&#x20;A股量化监控系统 - 架构概览



&#x20; 这是一个基于Python的A股量化监控系统，采用Flask Web框架 + SQLite缓存 + 多策略选股引擎的架构。

&#x20; │                     Web Application Layer                    │

&#x20; │                     (Flask + ECharts)                       │

&#x20; ├─────────────────────────────────────────────────────────────┤

&#x20; │  • 股票监控页面 (index.html)                                  │

&#x20; │  • 股票详情页 (stock\_detail.html)                             │

&#x20; │  • 选股策略页 (long\_term\_select.html)                         │

&#x20; │  • 用户管理页 (users\_manage.html)                             │

&#x20; │  • 回测页面 (backtest.html)                                   │

&#x20; └─────────────────────────────────────────────────────────────┘

&#x20;                            ↓ API

&#x20; ┌─────────────────────────────────────────────────────────────┐

&#x20; 📦 核心组件详解



&#x20; 1. Web应用层 (web\_app.py)



&#x20; - Flask框架: 提供RESTful API和Web界面

&#x20; - Flask-Login: 用户认证和权限管理

&#x20; - 角色系统:

&#x20;   - 管理员

&#x20;   - 开发者

&#x20;   - 访客

&#x20; - 默认用户:

&#x20;   - admin / admin123

&#x20;   - developer / dev123

&#x20;   - viewer / view123



&#x20; 2. 策略引擎层 (strategy\_engine.py)



&#x20; - StrategyEngine - 统一策略执行引擎

&#x20; - 运行6种中长线策略:

&#x20;   a. MA趋势 (20-60天)

&#x20;   b. MACD趋势 (15-30天)

&#x20;   c. 价值成长 (60-180天)

&#x20;   d. 底部反转 (15-30天)

&#x20;   e. 趋势加速 (10-20天)

&#x20;   f. 强势股回调 (5-15天)



&#x20; 3. 数据层 (stock\_cache\_db.py + stock\_async\_fetcher.py)



&#x20; - SQLite缓存:

&#x20;   - 股票基础信息表

&#x20;   - 主力资金表

&#x20;   - 龙虎榜表

&#x20;   - 技术指标表

&#x20; - 数据源:

&#x20;   - efinance (实时行情)

&#x20;   - akshare (历史数据)

&#x20;   - 新浪财经 (备用)

&#x20; - 缓存策略: 30分钟时效



&#x20; 4. 技术分析层 (tech\_indicators.py + advanced\_long\_term\_indicators.py)



&#x20; - 技术指标: MA, MACD, RSI, KDJ, BOLL

&#x20; - 短线策略: RSI短线, MACD短线, KDJ短线, 布林突破, 放量突破

&#x20; - 中长线策略: MA趋势, MACD趋势, 价值成长等



&#x20; 5. 配置层 (strategy\_config.py)



&#x20; - 策略参数配置

&#x20; - 市场环境推荐策略

&#x20; - 风险控制参数 (止损止盈)

&#x20; - ATR动态止损配置



&#x20; 🔑 关键特性



&#x20; 1. 权限控制: 基于角色的访问控制

&#x20; 2. 数据缓存: SQLite本地缓存，减少API调用

&#x20; 3. 多数据源: efinance + akshare + 新浪财经，确保数据可用性

&#x20; 4. 多策略: 短线 + 中长线，适应不同市场环境

&#x20; 5. 回测引擎: 支持历史数据回测

&#x20; 6. 市场情绪: 全市场情绪分析

&#x20; 7. 异步数据获取: 提高数据获取效率



&#x20; 📊 数据流



&#x20; 数据源 → StockAsyncFetcher → StockCache → StrategyEngine → Web API → Web界面

&#x20;   ↓                                                              ↓

&#x20; 缓存更新 → 技术指标计算 → 策略信号判断 → 用户界面展示
