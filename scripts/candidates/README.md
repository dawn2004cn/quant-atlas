# candidates

这个目录用于暂存“候选脚本”。

这里的脚本有几个特点：

- 暂时不进入主平台正式生产链路
- 仍有一定业务或运维价值，不能直接归档
- 后续可能被拆分、重构、迁入 `app/` 或重新分类到 `ops/` / `experiments/`

当前放入这里的，主要是历史上的“生产链路候选脚本”，先做目录归拢，暂不做平台化接入。

约定：

- 新的长期候选脚本优先放这里，而不是继续堆在 `scripts/` 根目录
- 如果脚本开始被稳定重复使用，应评估是否迁入 `app.cli`、`app.tasks` 或服务层
- 根目录中的同名脚本若存在，默认只作为兼容包装入口
