# 一次性脚本归档（One-off Script Archive）

本目录存放历史调试、一次性迁移、临时探索类脚本，已从仓库根目录迁出以减少根目录污染。

## 迁入标准

满足以下任一条件的根目录 `.py` 脚本应归档于此：
- 命名为 `find_*` / `fix_*` / `explore_*` / `check_*`（调试/探索类）
- 命名为 `run_*` 的手动同步脚本（非生产入口）
- 命名为 `phase*` / `restored_*` / `manual_*` 的迁移残留
- **未被** `app/`、`tests/`、`scripts/` 中任何代码 import

## 注意

- 这些脚本**不被生产代码引用**（已核实 `findstr /s /m` 无 import 命中）。
- 保留历史可追溯，**不删除**；如需复用，复制到工作目录或转为正式 `scripts/*.py`。
- 新增调试脚本请勿放回根目录，统一置于 `scripts/` 或 `scripts/dev/`。
