# Quant Atlas 金融技能集成 — 环境配置

## 快速开始（免费，无需 API Key）

安装完成后，在 Claude Code 中直接对话即可使用所有金融技能：

```
你：帮我分析贵州茅台 600519 的 2024 年年报
你：建一个宁德时代的 DCF 估值模型
你：出一份半导体行业 A 股投资策略
你：对比宁德时代和比亚迪的估值
```

Claude 会自动通过 AkShare MCP 获取数据（免费、无需注册）。

## 数据源配置

### Tier 0: Wind 万得（付费，最全面）

1. 注册：https://aifinmarket.wind.com.cn/#/home
2. 获取 API Key（以 `ak_` 开头）
3. 创建 `scripts/mcp-servers/wind-mcp/mcp_config.json`：

```json
{
  "api_key": "ak_your-key-here"
}
```

4. 在 `.claude/settings.local.json` 的 `mcpServers` 中添加 wind 配置

### Tier 1: 同花顺 iFind（付费）

1. 注册：https://mcp.51ifind.com/
2. 获取 Auth Token
3. 创建 `scripts/mcp-servers/ifind-mcp/mcp_config.json`：

```json
{
  "auth_token": "your-jwe-token-here"
}
```

4. 在 `.claude/settings.local.json` 的 `mcpServers` 中添加 ifind 配置

### Tier 2: AkShare（免费，开箱即用）

已安装，无需配置。

### Tier 3: China News（免费，开箱即用）

已安装，无需配置。

## 多 Agent 编排器

使用 `scripts/financial_orchestrator.py` 进行多 Agent 协调：

```python
from scripts.financial_orchestrator import FinancialOrchestrator, AgentName

orch = FinancialOrchestrator()
pipeline = orch.create_pipeline("600519")

# 添加并行任务
t1 = pipeline.add_task(
    AgentName.MARKET_RESEARCHER,
    "分析白酒行业竞争格局",
)
t2 = pipeline.add_task(
    AgentName.MODEL_BUILDER,
    "构建 DCF 模型",
    depends_on=[t1],  # 依赖行业分析
)

# 计算执行批次
batches = FinancialOrchestrator.compute_execution_order(pipeline)
# [[t1], [t2]] — t1 先执行，t2 等 t1 完成后执行
```

## Quant Atlas 集成

金融技能通过以下方式与 Quant Atlas 原生能力集成：

1. **数据层**：MCP 服务器为 Claude 提供结构化金融数据接口
2. **回测引擎**：40+ 策略模型可用于验证金融分析中的交易观点
3. **图表系统**：前端模板支持 OHLCV 数据可视化
4. **LangGraph 研究 Agent**：可与金融技能互补，做深度量化研究

## 注意事项

- A 股代码格式：6 位数字（如 "600519"），无前缀
- 中国会计准则：25% 标准税率，12 月 31 日财年
- 涨跌停限制：±10%（主板），±20%（创业板/科创板）
- 所有数据需注明来源，未验证数据标记为 `[UNSOURCED]`
